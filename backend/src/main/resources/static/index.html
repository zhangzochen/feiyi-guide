HOW IT WORKS

不是背解说词，
而是读懂你的问题。

讲解员先理解你在问什么，再去知识库里找最相关的段落。答案下面会标出来源，重要信息可以回到原文核对。

  1. 01

    一座小型知识库

    把展品的历史、工艺、纹样、产地和参观提示拆成可检索的段落。

  2. 02

    先检索，再回答

    用向量相似度和关键词重合度混合检索，先找依据，再组织语言。

  3. 03

    答案可以追溯

    每条回答都带来源。找不到依据时，它会直接说“不确定”，而不是编一个故事。

ABOUT THIS GUIDE

让非遗被听懂，
也被记住。

“见物 · 知艺”是一个面向展馆场景的 AI 讲解员原型。它不替代讲解员，而是把展品背后那些容易被忽略的细节，变成可以随时追问的对话。

本项目为课程/展示原型，展品信息用于演示。现场参观请以展馆官方说明为准。
